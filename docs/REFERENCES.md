# Fuentes primarias

Consultadas el 2026-10-06. Orientan investigación; no respaldan capacidades A-BYSS ni acreditan certificación.

- [NASA — Human Integration Design Handbook](https://www.nasa.gov/human-integration-design-handbook/): antecedentes y métodos de factores humanos para sistemas espaciales.
- [NASA — Habitability Design](https://www.nasa.gov/directorates/esdmd/hhp/habitability-design/): estudiar distribución interior junto con volumen disponible.
- [Airbus Acubed — Transpose](https://acubed.airbus.com/projects/transpose/): investigación de cabinas modulares; no se asume producto operativo aplicable a estas naves.
- [Airbus — A350 cabin-to-cargo conversion](https://www.airbus.com/en/newsroom/stories/2020-09-first-a350-cabin-to-cargo-conversion-with-airbus-service-bulletin): antecedente de modificación de cabina; no extrapolar tiempos ni capacidad.

PAX-4, inventarios y umbrales P0 son propuestas propias pendientes de derivación y verificación.
